# Agent Architecture

This document outlines the roles of the specialized agents within the PurePill-habitatAI ecosystem.

## Developer Agent
The Developer Agent is responsible for implementing new features, writing code, and solving complex programming tasks. It focuses on creating functional and efficient code following the project's standards.

## Support Agent
The Support Agent provides assistance to users and other agents. It handles queries, provides documentation, and helps troubleshoot issues, ensuring a smooth user experience and developer workflow.

## Refactor Agent
The Refactor Agent focuses on improving the existing codebase. Its primary goals are to enhance code readability, optimize performance, and reduce technical debt without changing the external behavior of the system.
